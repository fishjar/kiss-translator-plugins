# Index-Translate

需要支持结构化图片解析的 KISS Translator 2.2.6 或更新版本。插件 API 1。

默认使用公开接口 `https://index-translate.bilibili.com/v1` 和 `Index-Translate-35B-A3B`，无需 API Key。提供单条文本翻译和视觉解析，不声明批量、布局或文字坐标能力。

在图片／截图翻译中选择本插件视觉服务，并选择原文识别、图片翻译或双语解析提示词。已有有效译文会直接使用；只有原文时，所选文本翻译服务负责补译。“仅识别”不会补译。默认提示词保持原文识别，不自动覆盖用户选择。

图片输出预算 4096 tokens，输出截断会报错。图片翻译结果为文本，不生成回填图片。公共服务的限流、可用性和免费政策由提供方决定。初版不声明 2B、9B 的图片能力，布局需后续独立实测。

参考：[官方调用脚本](https://github.com/bilibili/Index-Translate/blob/main/inference/llm/call_api.py)。浏览器使用自己的 User-Agent；脚本环境的 WAF 要求不能直接推断为扩展中需要伪装请求头。

本包应在对应宿主支持版本发布后上线，不兼容已发布的旧 2.2.5。

## 浏览器 Origin 配置

本次 Chrome/Edge 扩展实测，公共网关对扩展 Origin 返回 HTTP 412。请在设置搜索“禁用Origin名单”，保留已有条目并追加 `https://index-translate.bilibili.com`（不要包含 `/v1`），使用宿主已有的同源 Origin 重写功能。无需改写 User-Agent。插件不会自行更改全局规则。浏览器不支持该功能时，可配置自己托管的兼容网关或本地桥接地址。

实测：原文识别、仅译文、双语均可完成；将兜底服务设为不存在的测试引用时，两种直译仍成功，确认没有调用文本翻译。仅识别保留原文且不补译。布局坐标质量未获验证，因此未声明支持。
